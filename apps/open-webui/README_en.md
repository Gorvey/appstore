## Introduction

**Open WebUI** is a popular self-hosted AI chat interface that can connect to Hermes Agent through an OpenAI-compatible API.

## Features

- **Simplified Hermes Integration**: The install form exposes only the API base URL and API key needed to connect to Hermes Agent.
- **Reverse-Proxy Friendly Deployment**: The container exposes only its internal 8080 port, which fits 1Panel reverse-proxy access.
