## Introduction

**3X-UI** is an open-source web-based Xray-core control panel for configuring and monitoring VPN and proxy protocols.

## Features

- **Web panel**: Manage Xray-core service configuration from a browser.
- **Protocol management**: Configure and monitor multiple VPN and proxy protocols.
- **Docker deployment**: Runs with the official GHCR image and persists panel database and certificate directories.
