## Introduction

**MTranServer** is a high-performance offline translation model server with low resource usage, no GPU requirement, a Web UI, and compatible translation APIs.

## Features

- **Offline Translation**: The server downloads required language models on first use and then serves translation requests locally.
- **Low Resource Usage**: The official README describes about 50 ms average response time per request and server deployment without a GPU.
- **Compatible APIs**: Provides compatible endpoints for Immersive Translate, DeepL, DeepLX, Google Translate, and other clients.
