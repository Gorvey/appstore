## 产品介绍

**CliRelay** 是一款统一的 AI CLI 代理服务器，可将 Claude Code、Gemini CLI、OpenAI Codex、Amp CLI 以及 OpenAI 兼容客户端的请求代理到统一端点，并提供 Web 管理面板、请求日志、用量监控和多服务商渠道管理。

## 主要功能

- **统一代理端点**：为 AI 编程工具和 OpenAI 兼容客户端提供统一 API 入口。
- **多服务商管理**：支持 Gemini、Claude、Codex、Qwen、iFlow、Kimi、Vertex 和 OpenAI 兼容上游。
- **可视化运维**：内置 /manage Web 面板，支持请求日志、渠道状态、API Key 和系统监控。
