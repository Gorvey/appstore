## Introduction

**CliRelay** is a unified proxy server for AI CLI tools and compatible API clients, routing Claude Code, Gemini CLI, OpenAI Codex, Amp CLI, and OpenAI-compatible clients through one endpoint with a web management panel, request logging, usage monitoring, and multi-provider channel management.

## Features

- **Unified Endpoint**: Provides one API entry point for AI coding tools and OpenAI-compatible clients.
- **Multi-Provider Management**: Supports Gemini, Claude, Codex, Qwen, iFlow, Kimi, Vertex, and OpenAI-compatible upstreams.
- **Operational UI**: Includes the /manage web panel for request logs, channel status, API keys, and system monitoring.
