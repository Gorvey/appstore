## 产品介绍

**CPA Account Biopsy System** 是 CLIProxyAPI 的独立旁路 sidecar 服务，通过 management API 与主项目协作，不替换、不影响主项目原有安装方式。

## 主要功能

- **账号健康度面板**：展示账号池整体健康度与单账号状态（未探测、正常、额度/限流、401 封禁、已停用）
- **额度窗口可视化**：展示周限额、代码审查周限额、5 小时限额等额度信息
- **请求统计**：展示请求数、成功数、失败数、Tokens 等统计指标
- **账号管理**：支持手动启用、停用、删除账号
- **独立仪表台**：提供独立 Web 密码保护的仪表台，支持自动快照刷新和低频探测
