## Introduction

**Hermes Agent** is a self-hosted AI agent from Nous Research with gateway messaging, skills, memory, and an OpenAI-compatible API server.

## Features

- **Gateway and API Server**: Runs in gateway mode and exposes an OpenAI-compatible API for frontends such as Open WebUI.
- **Persistent Local State**: Stores config, sessions, skills, and memories in a persistent data directory so you can edit the .env later.
